# Workbar 后续开发计划（Backlog）

> 状态：讨论中 / 未实现。这里记录已经讨论清楚的设计结论，避免以后重复讨论。
> 每条都标了优先级和「不做」的边界。

## 1. 正计时 / 倒计时（P1）

**问题**：现在只有倒计时（按 `est_min` 算进度）。有些任务没有明确时长，或者本来就是「做了多久」的正计时需求。

**设计**

- Task 增加可选字段 `timer: "down" | "up"`，省略时推断：有 `est_min` → `down`；没有 → `up`。
- 倒计时（down）：圆环 = 已用 / 预估；文案 `已用 01:25 / 预计 30 分钟`；剩余不足 5 分钟变琥珀色。
- 正计时（up）：圆环 = 匀速转圈的「计时中」指示（不表示进度）；文案只显示 `已用 01:25`。
- 收起态细线：
  - down：保持现状，从两端向中间收缩；
  - up：固定长度（约全宽 25%，居中）+ 呼吸光，表示「在计时，没有终点」。
- MCP：`plan_day` / `add_tasks` / `update_task` 增加 `timer`；不给就按上面规则推断。

**不做**：番茄周期、通知音、暂停历史、自定义提醒。

## 2. 多任务同时计时 + 单行多任务单元（✅ 已实现，2026-10-21）

> 实现时设计有调整：原计划的「chip + 小绿点 / ◷」被去掉，改为**所有任务都用同一套展开单元**（单行，不增高）。下面是最终形态。
>
> 遗留：一行最多 3 个单元（宽度限制），多出来的折叠成右侧 `+N`（悬停显示列表）；是否提高到 4 个、以及"即将开始"与"并行计时"谁优先，待定。

**数据与计时规则**

- 数据层允许任意多个任务 `running: true`。
- ticker 给**所有** running 任务累加 `spent_sec`（小数秒跨 tick 累加，避免半秒 delta 被 floor 丢掉）。
- 「当前任务」仍然唯一（收起态最亮的那段 / 展开态高亮单元）。
- 点单元标题切换当前任务时，**旧任务自动暂停**；点圆环可以单独暂停/开始某个任务。

**展开态（单行，最多 3 个单元）**

- 每个单元 = 圆环（身份色）+ 标题 + 时间 + ✓，圆环颜色与收起态分段一一对应。
- **未开始**：只显示 `21:19 开始`（不显示已用时间、不画进度弧）；临近时右侧提示分档：`不到 1 小时` / `不到 30 分钟` / `不到 15 分钟` / `不到 10 分钟` / `不到 5 分钟`。
- **运行中**：`已用 / 预计`，超时显示琥珀色「超时 N 分钟」。
- **暂停**：只显示 `已用 / 预计`（不要"已暂停"文案，圆环上的播放图标表示状态）。
- 超过 3 个任务时折叠为 `+N`，悬停显示被折叠的任务。

**收起态分段显示**

| 同时 running 的任务数 | 显示 |
|---|---|
| 0（全部完成 / 没计划） | 什么都不显示 |
| 1 | 单线 |
| 2–3 | 等宽分段，**无缝隙**，靠颜色 + 亮度区分 |
| 4 及以上 | 只显示 3 段 |

- 排序：按任务 `start` 时间从左到右固定，当前任务段亮度 +20%，其他段 55–60%。
- 分段颜色（按序使用，避开语义色）：

  | 序号 | 颜色 | 渐变 |
  |---|---|---|
  | 1 | 靛蓝紫 | `#6E7BFF → #A57BFF` |
  | 2 | 青柠 | `#22D3EE → #2DD4BF` |
  | 3 | 玫红 | `#FB7185 → #F472B6` |

- 还没实现：超时/暂停的段内动效（呼吸）——目前只靠颜色和亮度。


## 3. 任务来源链接（P2，方案待细化）

**目标**：AI 把任务加进 Workbar 之后，点一下能打开对应的「工作现场」——项目文件夹、文件、issue 页面，或者（如果客户端支持）当时的对话。

**设计草案**

- Task 增加可选 `link`（URL / 路径）和 `source`（哪个客户端加进来的）。
- MCP：`plan_day` / `add_tasks` / `update_task` 增加 `link`；工具描述里要求 AI 只在知道确切位置时填写。
- 交互：展开态里，有 `link` 的任务标题后显示一个 `↗` 图标；点击打开；hover 显示来源。
- 安全性：
  - 只允许白名单 scheme：`http` / `https` / `file` / `vscode` / `cursor` 等编辑器；
  - `file` 链接默认只打开所在文件夹并选中文件（不直接执行）；
  - 未知 scheme 一律忽略并记日志；
  - 绝不允许执行任意命令。
- 已知限制：「回到原来那个 AI 对话」取决于客户端是否暴露可寻址 URL，无法保证。

**待定**：点标题打开还是单独图标；默认打开偏好（浏览器 / 文件夹）；是否展示 source。

## 4. `workbar_now` 工具（P2）

- MCP 增加 `workbar_now`：返回当前本地时间、当前任务（含已用/剩余）、接下来几项。
- 让 AI 能回答「现在该做什么」和重排当天的计划。
- 注：`workbar-core` 里已经有 `now_minutes()` / `today_weekday()` / `current_task()` 三个 helper（已随代码提交），可以作为实现基础。
