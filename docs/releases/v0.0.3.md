默认按 Alt+W，随时收起或展开 WorkBar。

## 更新内容

- 默认收起 / 展开快捷键由 `Ctrl+Alt+W` 调整为 `Alt+W`，快捷键设置窗口和托盘菜单同步更新。
- 统一应用窗口、托盘菜单、安装包和 MCP 服务中的 WorkBar 名称显示。
- README 增加可直接发送给 AI 客户端的 MCP 接入提示词、全局任务记录规则和常用操作说明。

## 安装与升级

下载并运行 `WorkBar-setup-win64.exe`，已有版本可直接运行新版安装包升级。

已保存的快捷键设置会保留。若升级后仍使用旧快捷键，可右键托盘图标 →「设置快捷键」→ 恢复默认并保存，或手动录入 `Alt+W`。

安装包已包含 MCP 服务。首次接入或安装后命令不可用时，请完全退出并重新打开终端和 AI 客户端；在 VS Code 等编辑器内使用时，也请重启编辑器。接入步骤见 [README](https://github.com/Obsucre777/WorkBar#快速开始)。
