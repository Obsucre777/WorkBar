安装 WorkBar 后，一行命令接入 AI。

## 安装与接入更简单

- Windows 安装器现在会自动把安装目录加入当前用户的 PATH，直接使用 `workbar-mcp` 即可。
- 安装包已包含 MCP 服务，无需单独下载，也无需填写完整安装路径。
- 重复安装不会重复添加 PATH；更换安装目录时会清理旧目录项。
- 卸载完成后移除对应的 PATH 项，保留其它软件的环境变量。
- 安装向导版可从 Windows“设置 → 应用 → 已安装的应用”或“控制面板 → 程序和功能”中找到 Workbar 并卸载。
- 安装和卸载时会检查该安装目录中的 MCP 进程占用，释放程序文件后继续操作。

## 开始使用

下载并运行 `WorkBar-setup-win64.exe`。已有 v0.0.1 的用户可以直接运行新版安装包升级。

安装后，完全退出并重新打开终端与 AI 客户端，再选择对应命令：

Claude Code：

```text
claude mcp add --transport stdio --scope user workbar -- workbar-mcp
```

Codex：

```text
codex mcp add workbar -- workbar-mcp
```

其它支持本地 stdio MCP 的客户端，将服务启动命令设为 `workbar-mcp`。
