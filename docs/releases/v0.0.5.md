WorkBar 现在支持中文和英文界面，可随时从托盘菜单切换。

## 更新内容

- 新增中英文界面，覆盖任务栏、托盘菜单、快捷键设置、提示及错误信息。
- 默认跟随系统语言：中文系统使用简体中文，其他系统使用英文。
- 右键托盘图标 →「语言 / Language」，可选择「跟随系统」「简体中文」或「English」。切换立即生效，重启后保留选择。
- 新增英文 README，并提供中英文文档切换入口。
- 补充语言偏好、文案完整性、英文布局和切换后的计时及快捷键回归检查。

## 安装与升级

下载并运行 `WorkBar-setup-win64.exe`，已有版本可直接运行新版安装包升级。

现有任务和快捷键设置会保留，任务标题保持原文。安装包已包含 MCP 服务，接入方式见 [中文 README](https://github.com/Obsucre777/WorkBar#快速开始)。

## English

WorkBar now supports English and Simplified Chinese interfaces.

- Task cards, tray menus, shortcut settings, hints, and error messages are localized.
- The default follows your Windows display language: Chinese uses Simplified Chinese; other languages use English.
- Right-click the tray icon → **Language** → **Follow system**, **简体中文**, or **English**. Changes apply immediately and your choice is remembered after restarting.
- English documentation is available from the language links in the README.

Run `WorkBar-setup-win64.exe` to install or upgrade. Existing tasks and shortcuts are preserved, and task titles stay in their original language. The installer includes the MCP server. See the [English README](https://github.com/Obsucre777/WorkBar/blob/main/README.en.md#quick-start) for setup instructions.
